# Glossaire FR → AR (ERP société)

Extension de [docs/landing/ar-glossary.md](../landing/ar-glossary.md) pour l'espace société.

Arabe standard avec la terminologie administrative et comptable **tunisienne** (حريف, منتوج, خلاص,
إذن التسليم…). Les choix ci-dessous sont ceux qui dominent dans le catalogue existant (mesure du
2026-09-27 sur 7 900 traductions) : les suivre pour toute nouvelle traduction. Vocatif pluriel de
politesse (« قوموا بـ… », « أدخلوا… »), comme dans le reste de l'interface.
